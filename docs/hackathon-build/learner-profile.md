# Learner Profile

- Name: Andrea Volpini
- Background: Founder at WordLift with extensive experience in web publishing, semantic technologies, knowledge graphs, agentic SEO, product development, and AI-assisted software delivery.
- What brought them to the hackathon: Turn WordLift's existing AI Audit capabilities into a genuinely open, chat-first WebMCP application that helps websites serve agentic audiences.

## Project Idea
- Initial idea: Build a new open-source, WordLift-branded application for the WebMCP Challenge. A CMO, SEO, GEO, site owner, or their AI agent enters a URL in ChatGPT and receives AI Audit scores, prioritized recommendations, and an ontology-ready map of the actions the site supports. The experience starts with an executive summary and allows expansion into technical evidence. The new public application will build on the existing private AI Audit API and agent tools while adding meaningful WebMCP-native functionality in the public project.

- Languages/frameworks known: Existing reference stack is React 19, TypeScript, Vite, Gemini, ScrapingBee, and Google Cloud Run. The new project may reuse that architecture and visual framework where appropriate without copying proprietary code into the public repository.
- AI coding tools used before: Regular use of AI coding agents and agentic product workflows, including Codex.
- Prior experience planning before coding: Strong. Prefers establishing mission, product model, architecture, and evaluation criteria before implementation.

## Build Preferences
- Preferred pace: Fast, decisive, and iterative, with short verification checkpoints.
- Likely support needs: Scope discipline; public/private boundary design; capability ontology; WebMCP tool contracts; evidence and scoring model; challenge eligibility; tests, demo narrative, and documentation.
- Notes for downstream commands: Preserve WordLift branding while making extension points clear for outside contributors. Keep the core experience chat-first: enter a URL and the system takes it from there. Reuse the existing AI Audit visual language, but make supported site actions—not a generic SEO checklist—the product's center of gravity. Use Alpina.travel as an agent-proven reference case. Avoid beginner-level coding explanations unless requested.
